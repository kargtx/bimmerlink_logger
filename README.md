# Bimmerlink Logger · BMW102

Веб-приложение для просмотра и анализа логов [BimmerLink](https://bimmerlink.app) с телефона и компьютера. Сделано для BMW102.

- Загрузка CSV перетаскиванием или кнопкой, архив заездов с поиском и сортировкой
- Графики на uPlot: «вместе» (своя ось на каждую единицу), «раздельно» (синхронный курсор), «в процентах»
- Приближение выделением мышью, двумя пальцами или ползунками; длинные логи догружаются по отрезку
- Пики выбранных параметров, статистика min / сред / max и время максимума
- Поиск разгонов (0–100, 60–100, 80–120, 100–200 км/ч) и выходов за пороги (температуры)
- Пресеты на сервере, сравнение двух заездов, экспорт PNG, исходный CSV, ссылка на текущий вид
- Работает как приложение на телефоне (PWA), интерфейс открывается и без сети

## Требования

- Node.js 22 или новее
- npm 10+

## Установка и запуск

```bash
cd path/to/bimmerlink_logger
npm install
npm start
```

Откройте http://localhost:3000. Для разработки — `npm run dev` (перезапуск при изменениях).

### Настройки

Скопируйте `.env.example` в `.env` и поправьте при необходимости:

| Переменная    | По умолчанию | Назначение                              |
| ------------- | ------------ | --------------------------------------- |
| `PORT`        | `3000`       | Порт HTTP-сервера                       |
| `DATA_DIR`    | `./data`     | База, исходные CSV и разобранные данные |
| `BACKUP_DIR`  | `./backups`  | Куда складывать резервные копии         |
| `BACKUP_KEEP` | `14`         | Сколько последних копий хранить         |

### pm2

```bash
pm2 start ecosystem.config.js
```

Запускает сервер и ежедневную резервную копию в 04:00.

### Docker

```bash
docker compose up -d --build
```

Данные хранятся в `./data` на хосте.

## Данные

```
data/
  logs.db            SQLite: заезды, параметры со статистикой, пресеты
  raw/<id>.csv       исходные файлы — не удаляйте, из них можно всё пересобрать
  parsed/<id>.json.gz разобранные ряды для графиков
```

При первом запуске новой версии записи из старой таблицы `sessions` автоматически переносятся в новую схему (старая таблица переименовывается в `sessions_legacy` и не удаляется).

### Формат CSV

Ожидается лог BimmerLink: первая колонка — время в секундах от старта, остальные — параметры. Поддерживаются разделители `,` `;` и табуляция, BOM, кавычки, десятичная запятая. Дата записи берётся из имени файла (`2026-05-09_23-32-53.csv`).

BimmerLink опрашивает параметры по кругу, поэтому до первого опроса в колонке стоит «0». Такие значения считаются пропусками и не влияют на графики и статистику.

### Словарь параметров

Русские названия, единицы, группы и пороги тревоги задаются в `src/channels.js`. Единицы указаны для метрических настроек BimmerLink. После правки словаря или парсера пересоберите все логи:

```bash
npm run reparse
```

## Команды

| Команда           | Что делает                                       |
| ----------------- | ------------------------------------------------ |
| `npm start`       | Запуск сервера                                   |
| `npm run dev`     | Запуск с автоперезапуском                        |
| `npm test`        | Тесты (парсер, анализ, API, перенос старой базы) |
| `npm run lint`    | ESLint                                           |
| `npm run format`  | Prettier                                         |
| `npm run reparse` | Пересобрать все логи из `data/raw`               |
| `npm run backup`  | Резервная копия базы и исходных CSV              |

## API

| Метод      | Путь                                          | Описание                                  |
| ---------- | --------------------------------------------- | ----------------------------------------- |
| GET        | `/api/logs`                                   | Список заездов                            |
| POST       | `/api/logs`                                   | Загрузка (`multipart`: `logfile`, `name`) |
| GET        | `/api/logs/:id`                               | Заезд: параметры, статистика, события     |
| PATCH      | `/api/logs/:id`                               | Изменить `name`, `notes`                  |
| DELETE     | `/api/logs/:id`                               | Удалить заезд и его файлы                 |
| GET        | `/api/logs/:id/data?ch=0,3&from=&to=&points=` | Ряды для графика с прореживанием          |
| GET        | `/api/logs/:id/raw`                           | Исходный CSV                              |
| GET/POST   | `/api/presets`                                | Пресеты                                   |
| PUT/DELETE | `/api/presets/:id`                            | Изменить / удалить пресет                 |
| GET        | `/healthz`                                    | Проверка работоспособности                |
